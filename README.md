# Healthcare Readmission Analysis

## Overview
This project analyzes hospital diabetes patient data to explore factors associated with hospital readmission. It includes data preparation, exploratory data analysis, visualizations, and machine learning model evaluation.

## Objectives
- Examine readmission outcomes.
- Explore relationships between patient and hospital-related features and readmission.
- Compare model performance and review feature importance.
- Visualize patterns and risk stratification results.

## Project Structure
- `diabetes_data/`: Dataset and ID mappings
- `notebooks/`: Main analysis notebook
- `visualizations/`: Analysis charts and model results
- `diabetic_data.csv`: Dataset
- `diabetic_data_cleaned.csv`: Cleaned dataset
- `01_target_distribution.png`: Target distribution chart
- `EXECUTIVE_SUMMARY.txt`: Project summary

## Tools
- Python
- Pandas and NumPy
- Matplotlib and Seaborn
- Scikit-learn
- Google Colab / Jupyter Notebook

## How to Explore
Open `notebooks/Healthcare_Analytics_Project.ipynb` in Google Colab or Jupyter Notebook and run the analysis cells in order.

## Note
This project explores associations in a diabetes-related hospital dataset. Its findings should not be interpreted as clinical advice or proof of causation.
