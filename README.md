# Healthcare Readmission Analysis

## Overview
This project analyzes hospital diabetes patient data to explore factors associated with hospital readmission. It includes data preparation, exploratory data analysis, visualizations, and machine learning model evaluation.

## Objectives
- Examine the distribution of readmission outcomes.
- Explore relationships between patient and hospital-related features and readmission.
- Compare model performance and review feature importance.
- Visualize patterns and risk stratification results.
